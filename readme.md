# DayX

DayX ist eine einfache und minimalistische Website, mit der du die Anzahl der Tage seit einem bestimmten Startdatum zählen kannst.

Du kannst Counter für verschiedene Aktivitäten, Ziele oder persönliche Vorhaben erstellen. Jeder Counter besitzt einen eigenen Namen, ein Startdatum und optionale Notizen. Der aktuelle Tag wird automatisch anhand des Startdatums berechnet.

DayX wurde entwickelt, um eine einfache Möglichkeit zu bieten, den Fortschritt über einen längeren Zeitraum zu verfolgen, ohne unnötige Funktionen oder komplizierte Einstellungen.

---

## Funktionen

* Mehrere Counter erstellen
* Automatische Berechnung des aktuellen Tages
* Individueller Name für jeden Counter
* Individuelles Startdatum
* Optionale Notizen
* Counter löschen
* Speicherung der Counter im Local Storage
* Counter bleiben nach dem Neuladen der Website erhalten
* Einfaches und minimalistisches Design
* Hover-Effekte für Buttons
* Keine Anmeldung erforderlich
* Keine Datenbank erforderlich

---

## Verwendung

1. Klicke auf **„Counter anlegen“**.
2. Gib einen Namen für deinen Counter ein.
3. Wähle ein Startdatum aus.
4. Füge optional Notizen hinzu.
5. Klicke auf **„Counter anlegen“**.
6. DayX berechnet automatisch den aktuellen Tag.

### Counter löschen

Jeder erstellte Counter besitzt einen **Löschen-Button**.

Durch einen Klick auf den Button kann der jeweilige Counter direkt entfernt werden.

### Beispiel

```text
Programmieren

Tag 42

Seit dem 20.07.2026
```

Der Counter wird automatisch anhand des Startdatums aktualisiert.

---

## Speicherung

DayX verwendet den **Local Storage** deines Browsers, um deine Counter zu speichern.

Dadurch bleiben deine Counter auch nach dem Neuladen oder erneuten Öffnen der Website erhalten.

Die Daten werden lokal in deinem Browser gespeichert und nicht an einen Server übertragen.

Wenn die gespeicherten Website-Daten deines Browsers gelöscht werden, können auch die gespeicherten Counter verloren gehen.

# DayX

DayX is a simple and minimalist website that allows you to count the number of days since a specific start date.

You can create counters for different activities, goals, or personal projects. Each counter has its own name, start date, and optional notes. The current day is automatically calculated based on the start date.

DayX was created to provide a simple way to track progress over a longer period of time without unnecessary features or complicated settings.

---

## Features

* Create multiple counters
* Automatic calculation of the current day
* Custom name for each counter
* Individual start date
* Optional notes
* Delete counters
* Counters are stored using Local Storage
* Counters remain available after reloading the website
* Simple and minimalist design
* Hover effects for buttons
* No account required
* No database required

---

## Usage

1. Click **"Create Counter"**.
2. Enter a name for your counter.
3. Select a start date.
4. Optionally add notes.
5. Click **"Create Counter"**.
6. DayX automatically calculates the current day.

### Deleting a Counter

Each created counter has a **Delete button**.

Clicking the button allows you to directly remove the selected counter.

### Example

```text
Programming

Day 42

Since 20.07.2026
```

The counter is automatically updated based on the start date.

---

## Storage

DayX uses your browser's **Local Storage** to save your counters.

This allows your counters to remain available after reloading or reopening the website.

The data is stored locally in your browser and is not sent to a server.

If the website data stored by your browser is deleted, the saved counters may also be lost.
